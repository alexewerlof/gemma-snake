# Intro

This is a simple one-shot example to demonstrate [how VS Code Copilot can be used with Gemma 4 26B running in LM Studio](https://blog.alexewerlof.com/p/local-llms-for-agentic-coding). The entire prompt was this (no AGENTS.md):

```
Create the game snake in the browser.

Architecture:

1. Simple browser runtime using the DOM API directly
2. No build or compile steps
3. There should be an index.html file that loads styles.css and index.js (module format) and the entire game is in one file.
4. Score tracking would be nice.
5. Difficulty scaling wouldn't be necessary
6. High score is not needed at this stage
7. A game over screen is needed
```

I intentionally didn't do any follow up feature requests to show case what the vanilla model is capable out of the box.

[Play Live](https://alexewerlof.github.io/gemma-snake/)
